Password Strength Analyzer

Project Description
The Password Strength Analyzer is a Java-based application that evaluates the strength of user-entered passwords.

Features
- Checks password length.
- Checks uppercase and lowercase letters.
- Checks numbers and special characters.
- Detects common passwords.
- Identifies repeated characters and predictable patterns.
- Provides password improvement suggestions.
- Generates a random strong password.

Technologies Used
- Java
- Scanner
- Regular Expressions
- HashSet
- ArrayList
- SecureRandom

How to Run
1. Download the Java source file.
2. Open the terminal in the project folder.
3. Compile using:

`javac PasswordStrengthAnalyzer.java`

4. Execute using:

`java PasswordStrengthAnalyzer`

Expected Outcome
The application displays a password strength score, identifies security weaknesses, and suggests improvements.
